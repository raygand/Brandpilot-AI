## Interpretation and limits

- This remains a browser-local learning simulation. It does not connect to a sales database, a live buyer, a generative-AI service, or a shared account backend.
- Financial figures are disclosed assumptions. Existing plan multipliers are retained (launch outlay ×1/×2/×4.55; assumed units ×0.333/×1/×2.5), so higher-resource scenarios explicitly require extra launch budget/stock. Positive unit contribution alone does not imply launch profitability. Tax, interest, inventory financing and other overhead are not forecast.
- Text-feature buyer grading rewards rubric concepts; it cannot verify evidence or judge a real buyer's acceptance.
- Browser download-event notification timed out, but the actual downloaded files were subsequently found and read in the browser download directory. Thai, English and Chinese UTF-8 summaries were delivered (6,541 / 2,841 / 3,695 bytes in the exercised sessions), with localized headings, no unresolved tokens, and the Chinese sample preserving the exact QA draft and buyer answer. The event-listener limitation did not prevent actual downloads.
- Mobile evidence uses a real 390×844 iframe viewport, not a physical iOS/Android device. Safari, native mobile keyboard and screen-reader end-to-end behavior were not separately tested.
- A legacy native JavaScript reset confirmation stalled the browser test API. Reset was replaced with an accessible in-app dialog and Cancel/Confirm were then verified successfully.
